# Better Branch Beacon

A Visual Studio Code extension that displays your current git branch in a prominent sidebar panel with large, easy-to-read text.

## Features

- Displays the current git branch in a dedicated sidebar panel
- Large, bold text for easy visibility
- Automatically updates when you switch branches
- Works with any git repository

## Usage

1. Install the extension
2. Open a folder/workspace that contains a git repository
3. Click on the Branch Beacon icon in the Activity Bar (left sidebar)
4. The current branch name will be displayed in large text

## Development

To develop this extension:

1. Clone the repository
2. Run `npm install` to install dependencies
3. Press F5 to open a new VS Code window with the extension loaded
4. Make changes and reload the window to see updates

## Building

```bash
npm install
npm run compile
```
